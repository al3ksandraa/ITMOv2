# ui/reset-task-filters Specification

## Purpose
Кнопка «Сбросить фильтры» позволяет быстро вернуть список задач к базовому виду без поиска и узких фильтров, не затрагивая текущую сортировку и данные задач.

## Requirements

### Requirement: Reset button clears search and priority and sets status to all
Система SHALL предоставить кнопку «Сбросить фильтры», которая при нажатии очищает строку поиска, устанавливает фильтр по приоритету в «Все» и фильтр статуса в «Все», выполняя локальную перерисовку списка.

#### Scenario: Reset from non-default filters
- **WHEN** пользователь вводит текст в поле поиска, выбирает приоритет «Высокий» и нажимает «Выполненные»
- **THEN** после нажатия «Сбросить фильтры» поле поиска пустое, фильтр по приоритету равен «Все», статус равен «Все», список перерисован локально

#### Scenario: Idempotent reset
- **WHEN** фильтры уже в состоянии по умолчанию и пользователь нажимает «Сбросить фильтры»
- **THEN** состояние и список остаются валидными; выполняется локальная перерисовка без ошибок

### Requirement: Reset does not change sort
Система SHALL сохранять текущую сортировку списка задач при сбросе фильтров.

#### Scenario: Reset does not change sort
- **WHEN** пользователь включает сортировку по дедлайну и затем нажимает «Сбросить фильтры»
- **THEN** сортировка остаётся включённой как была до сброса

### Requirement: No network requests during reset
Система SHALL не выполнять сетевые запросы к API при нажатии «Сбросить фильтры»; изменения происходят только в локальном состоянии и отрисовке.

#### Scenario: No network requests
- **WHEN** пользователь нажимает «Сбросить фильтры»
- **THEN** не выполняется ни один сетевой запрос к `/api/*`

### Requirement: Selection checkboxes behavior on reset
Система SHALL перерисовывать список задач при сбросе фильтров. Выбор задач чекбоксами не сохраняется между перерисовками и будет очищен при сбросе.

#### Scenario: Selection cleared on reset
- **WHEN** пользователь отмечает несколько задач чекбоксами и затем нажимает «Сбросить фильтры»
- **THEN** после перерисовки все чекбоксы выбора задач не отмечены

#### Scenario: Bulk actions collect selection before render
- **WHEN** пользователь запускает массовое действие, пока есть отмеченные задачи
- **THEN** система собирает выбранные идентификаторы до перерисовки и применяет действие к этим задачам, даже если перерисовка сбрасывает визуальный выбор
