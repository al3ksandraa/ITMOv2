# Доказательства повторной проверки исправленного Mini Shop

- [audit-summary.json](audit-summary.json) содержит повторные HTTP-атаки V-01–V-11; ни одна не подтверждена.
- [tests-summary.json](tests-summary.json) и [tests.log](tests.log) фиксируют 60/60 успешных тестов: 16 поставляемых и 44 защитных.
- [H-09-copilot.json](H-09-copilot.json) содержит два фактических ответа Copilot, контрольный и атакующий входы, исполнение решений и прямую передачу опасного решения.
- [make-results.json](make-results.json) фиксирует успешный запуск `make step6` и `make test` внутри WSL Ubuntu 2.

Каждый HTTP-сценарий использовал отдельный процесс на `127.0.0.1` с одноразовыми синтетическими данными. `sandbox.py` не изменялся; файловая граница не расширялась.
