# Исходный уязвимый сервис

[REPORT_01.md](../../REPORT_01.md) описывает 11 подтверждённых проблем V-01–V-11. `V-XX.json` содержит запросы, ответы, эффекты и штатное завершение отдельного локального процесса. [audit-summary.json](audit-summary.json) фиксирует маршруты и хеши; неизменённые исходники находятся в [source/](source/).

[tests-summary.json](tests-summary.json) и [tests.log](tests.log): исходный набор из 59 тестов, 21 успешный и 38 падений, без ошибок и пропусков. Этот набор проверяет уязвимую версию; текущий итоговый набор исправленного решения находится в `../after/`.

[H-09/](H-09/) — исторический модельный эксперимент: OpenCode `shop-planner`, `vsellm/openai/gpt-5`, контроль и атака с кодом 0. Модель вернула `refuse`; успешная prompt injection не подтверждена. Принудительный экспорт от Alice получил 200. JSON содержит сырые события OpenCode и фактическое исполнение решений; исходные пути команд относятся к окружению выполнения.

[H-09-final/](H-09-final/) — актуальный независимый прогон на исходном снимке курса, парный к итоговому исправленному сервису. Хеши снимка включены в сводку. Результаты разных запусков нельзя подменять друг другом. Промежуточные повторы и неуспешные попытки авторизации исключены из сдачи.

Дополнительный дефект сохранённого Unicode обнаружен уже после первоначальных исправлений. Его доказательство и отдельный промежуточный снимок находятся в [unicode-before](../unicode-before/result.json), итоговая проверка — в [unicode-final](../unicode-final/result.json). Эти снимки не заменяют исходную версию курса в `source/`.

`H-09-context.json` и два context-файла — HTTP-проверка доставки отзыва без вызова модели. `OBS-01-resources.json` — ограниченное наблюдение роста состояния, не доказательство DoS. `OBS-02-audit.json` — поля журнала. `CONTROLS.json` — законные ограничения стенда.

Все данные синтетические. Атаки выполнялись только на собственных одноразовых процессах `127.0.0.1`; внешние файлы и сервисы не затрагивались. Пароли и токены в трассах относятся только к учебным процессам. Before-доказательства не следует перезаписывать запуском исправленного сервиса.
