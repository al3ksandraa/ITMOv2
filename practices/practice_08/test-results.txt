Практика 8. Проверка клиентских тестов

Проверки охватывают валидацию пустого названия и пробелов, отправку формы с клавиатуры,
видимую карточку после создания, защиту от повторной отправки, загрузку списка, пустой ответ,
ошибки и восстановление. Отдельно проверены активные фильтры, поздний ответ списка,
чекбоксы на мобильном экране и массовый выбор.

Playwright подменяет HTTP-ответы, используя массив для пустого списка, объект Task
для успешного создания с кодом 201 и объект с полем error для сбоя. Отдельный сценарий
создаёт задачу через настоящий API и проверяет её после перезагрузки страницы.
У каждого теста отдельная временная копия сервера с собственным хранилищем.
