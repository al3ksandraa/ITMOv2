# Анализ процесса: AS IS и TO BE

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный diff. Все дополнения и исправления поручайте агенту в чате.

## AS IS

Событие и поток данных подтверждены TRAINING_PR.diff и контекстом.

- Участники: клиент HTTP API (внешний актор), FastAPI-приложение (app/api.py), ReviewService (app/review_service.py), абстракция LLM.
- Поток:
  1. Клиент отправляет POST /api/reviews с телом JSON, содержащее ключ "diff" со строкой диффа (context.md, app/api.py 35-37).
  2. Хендлер `create_review(payload: dict)` читает `payload["diff"]` и вызывает `review_service.review(...)` (app/api.py 35-37).
  3. `ReviewService.review(diff: str)` формирует промпт вида "Review this pull request and find problems:\n{diff}", вызывает `llm.generate(prompt)` и возвращает словарь `{ "comment": answer }` (app/review_service.py 19-22).
  4. Клиент получает ответ JSON `{ "comment": str }` (context.md).
- Известные проблемы и точки отказа:
  - Отсутствует валидация входа: прямой доступ к `payload["diff"]` может привести к KeyError и 500 при отсутствии поля (app/api.py 35-37; problem.md).
  - Не ограничен размер `diff`: потенциальные сбои/задержки на стороне LLM (problem.md, анализ по TRAINING_PR.diff).
  - Нет обработки ошибок LLM: исключения из `generate` не перехватываются (app/review_service.py 19-22).


## TO BE

Минимальное улучшение первого рабочего сценария без изменения интерфейса:

- На уровне FastAPI добавить схему запроса (валидация поля `diff: str`) для возврата 422 на невалидный вход.
- Сохранить текущий контракт ответа `{ "comment": str }`.
- Зафиксировать обработку ошибок LLM на уровне сервиса/роута как будущую задачу (в этом инкременте — без изменений).

## Разница

| Что меняется | AS IS | TO BE | Как проверим изменение |
|---|---|---|---|
| Валидация входа | Нет схемы; KeyError -> 500 | Схема запроса; 422 при отсутствии/неверном `diff` | Негативный запрос без `diff` возвращает 422 |
| Контракт ответа | Фактически `{"comment": str}` | Закреплён документом и response-моделью (план) | Позитивный запрос возвращает `{"comment": str}` |
| Обработка ошибок LLM | Нет перехвата | Не меняется в этом инкременте | Зафиксировано как риск; проверка — см. integration tests |
| Размер `diff` | Не ограничен | Не меняется в этом инкременте | Н/Д |
