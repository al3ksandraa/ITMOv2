## Context Pack для первого рабочего сценария

### Факты и правила

- Эндпоинт POST /api/reviews: функция create_review(payload: dict) -> dict[str, str] возвращает review_service.review(payload["diff"]).
- ReviewService.review(diff: str) формирует промпт: "Review this pull request and find problems:\n{diff}", вызывает llm.generate и возвращает {"comment": answer}.
- /health возвращает {"status": "ok"}.

### Формат входа и результата

- Вход: JSON с ключом "diff" (str) в POST /api/reviews.
- Результат: JSON {"comment": str}.

### Ограничения и запрещённые действия

- Использовать только данные из TRAINING_PR.diff; не добавлять внешние факты.
- Текущая реализация не содержит схем валидации и ограничений на размер; обработка ошибок LLM отсутствует.

### Хороший пример

- POST /api/reviews с валидным {"diff": "diff --git ..."} -> 200 и {"comment": "..."}.

### Плохой пример

- POST без ключа "diff" -> в текущем коде вероятен KeyError и 500.
### Что пока неизвестно

- Ограничения и параметры LLM (таймауты/лимиты).
- Требования к аутентификации и ограничению нагрузки.
- Требуемая структура вывода (текст vs структурированный список).
