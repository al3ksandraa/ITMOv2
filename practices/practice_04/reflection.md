# Описание скилла task-data-doctor

Скилл помогает проверить и исправить данные в файле `practice_04/task_planner/data/tasks.json`, чтобы поддерживать инвариант данных. Скилл вызывает MCP `tasks-lint-fix` и, если проблем нет, запускает проверку `sh scripts/check.sh`. Если инвариант данных нарушен, снова вызывает MCP, чтобы исправить битые данные на значения по умолчанию из домена значений. При этом скилл не ломает контракт `Task`.

# Рефлексия

Идеи для скилла и MCP обсуждали вместе с агентом, затем выбрали один вариант связки. Агент не всегда полностью заполнял markdown-файлы (иногда оставался один заголовок), приходилось добавлять в промпт указания о самопроверке. Артефакты среды находятся в `.opencode/` (skill, MCP, hook, servers.json), чтобы не было дублирования в папке практики

В `practice_04/docs/` лежит файл с отчетом агента по созданию скилла
