# Планировщик задач и дедлайнов

Простой сервис с фронтендом для составления списка задач и дедлайнов.

Функции:
- Добавление задач с названием, описанием, приоритетом и дедлайном
- Просмотр списка, сортировка по дедлайну
- Отметка выполнения, редактирование и удаление задач
- Локальное сохранение на сервере в `data/tasks.json`

Как запустить:
1. Требуется Node.js 18+ (без дополнительных зависимостей)
2. Варианты запуска:
   - Если установлен make: `make run`
   - Без make: из папки `task_planner` выполнить `node server.js`
3. Открыть: http://localhost:3000

Подсказки:
- Windows PowerShell/CMD: перейдите в папку `practices/practice_04/task_planner` и выполните `node server.js`
- macOS/Linux: то же самое; остановка сервера — Ctrl+C

Полезные команды:
- `make run` — запустить сервер на 3000 порту
- `make reset` — очистить список задач (обнулить `data/tasks.json`)

Структура:
- `server.js` — минимальный HTTP-сервер и REST API (`/api/tasks`)
- `public/` — статические файлы фронтенда
- `data/tasks.json` — хранилище задач (JSON)

Заметки по данным:
- Дедлайн хранится в виде ISO-строки (UTC). В UI используется `datetime-local` в вашей локальной зоне. Конвертация выполняется на клиенте.
