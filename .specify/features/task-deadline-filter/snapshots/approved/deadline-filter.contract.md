# Контракт: Фильтр по сроку (task-deadline-filter)

Кратко:
- Режимы: `all | overdue | today | no-deadline`.
- Комбинация: логическое И с поиском/приоритетом/статусом.
- Время и TZ: today по локальным границам дня `[startOfToday; startOfTomorrow)`, overdue — строго `< now`.
- Выполненные: overdue всегда исключает выполнённые; today следует статус-фильтру.
- Сброс: поиск/приоритет/статус/срок → `all`, сортировка сохраняется, без дополнительных API-запросов.
- Пустая выдача: «Нет задач по выбранным критериям» в `<div id="empty-state" role="status">` после `#task-list`.
